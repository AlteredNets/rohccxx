# rohccxx v0.8.0-rc.5

Version 0.8.0-rc.5 is a pre-v1 release candidate. It fixes Issue #63, a
residual stale compact PT-0 alias after CID/profile replacement discovered
during published RC4 long-duration validation.

The Issue #63 Lane D failure produced two quarantined silent mutations in the
published RC4 post-publish redline campaign. Those witnesses are preserved as a
permanent deterministic regression, alongside the existing Issue #32
regressions.

The clean surviving RC4 A/B/C scale envelope reached 255,000,000 attempted
packets, 254,999,945 accepted packets, and 254,999,945 byte-exact outputs. The
full RC4 campaign accumulated 304.1705 GiB of traffic over 48.594 active hours.

Issue #63 fix validation completed 1,000,000 focused fuzz executions, forward
WAN validation, and reverse WAN validation with zero silent mutations, zero
cross-profile accepts, and zero cross-flow errors.

This candidate retains the v0.8.0 ABI version and the pre-v1 product maturity.
It does not claim v1 readiness, production certification, DoD approval, Army
approval, or universal safety outside the tested envelope.

The release-candidate workflow is expected to register 293 CTest cases, pass
290 executed cases, and skip the three optional external-oracle interoperability
tests when those external oracles are not provided. The pinned rohc-lib
interoperability oracle remains
70589cc2b8650f82453815c84ba41b0ab80a52a0.

The publication artifact plan is unchanged from RC4: source-with-submodules
archive, Debian package, buildinfo, and SHA256SUMS generated by the release
candidate workflow. RC5 must not be tagged or published until the release PR is
reviewed, authorized, and merged.

# rohccxx v0.8.0-rc.4

Version 0.8.0-rc.4 is a pre-v1 release candidate. It contains the Issue #32
PT-0 generation/profile alias-family fix that blocked promotion of
v0.8.0-rc.3.

The original four RC3 witnesses are preserved as deterministic regressions.
The residual WAN witness family exposed during the Issue #32 fix lane is also
preserved as a deterministic regression. The fix lane passed forward and
reverse bounded WAN validation after transport was proven healthy.

The preceding v0.8.0-rc.3 redline campaign achieved 253,782,752 attempted
packets, 302.5367 GiB of original traffic, and 38.651 active hours. That RC3
campaign found no new failures outside the historical quarantined Issue #32
family, but RC3 promotion remained blocked by Issue #32.

This candidate retains the v0.8.0 ABI version and the pre-v1 product maturity.
It does not claim v1 readiness, production certification, Army approval, or
universal safety outside the tested envelope.

The release-candidate workflow is expected to register 292 CTest cases, pass
289 executed cases, and skip the three optional external-oracle interoperability
tests when those external oracles are not provided. The pinned rohc-lib
interoperability oracle remains
70589cc2b8650f82453815c84ba41b0ab80a52a0.

The publication artifact plan is unchanged from RC3: source-with-submodules
archive, Debian package, buildinfo, and SHA256SUMS generated by the release
candidate workflow. RC4 must not be tagged or published until the release PR is
reviewed, authorized, and merged.

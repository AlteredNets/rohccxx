# rohccxx v0.8.0-rc.6

Version 0.8.0-rc.6 is a pre-v1 release candidate. It adds an opt-in
decompressor acknowledgement for successfully accepted IR and IR-DYN context
refreshes on formal PT-0 profiles. The feature is disabled by default and does
not change decompression acceptance or byte-exact output semantics.

The acknowledgement is positively correlated to the accepted refresh. It is
not emitted for compact packets or rejected refreshes, and it does not
overwrite pending negative feedback. Permanent regressions cover default-off,
IR, IR-DYN, compact-packet, enable/disable, transactional-failure, and pending
feedback behavior.

Integration validation used SATCOM's wired reverse-feedback path. The SATCOM
suite passed 185 of 185 tests. Physical two-node validation passed in both
directions with 298 accepted and byte-exact packets per direction, 541 refresh
ACKs generated and routed, and zero silent mutations, cross-profile accepts,
cross-flow errors, crashes, or hangs. Measured steady-state relative goodput
improved from 1.07143x to 2.27209x under the defined integration benchmark.

This candidate retains the v0.8.0 ABI version and the pre-v1 product maturity.
It does not claim v1 readiness, production certification, DoD approval, Army
approval, or universal safety outside the tested envelope.

The release-candidate workflow is expected to register 301 CTest cases, pass
298 executed cases, and skip the three optional external-oracle interoperability
tests when those external oracles are not provided. The pinned rohc-lib
interoperability oracle remains
70589cc2b8650f82453815c84ba41b0ab80a52a0.

The publication artifact plan is unchanged from RC5: source-with-submodules
archive, Debian package, buildinfo, and SHA256SUMS generated by the release
candidate workflow. RC6 must not be tagged or published until the release PR is
reviewed, authorized, and merged.
